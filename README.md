## History and preservation

- Every original commit is preserved without squashing or rewriting. Each source's main commit is a parent of its import merge.
- Original branches are preserved as `archive/<repository>/<branch>`; original tags are preserved as `archive/<repository>/<tag>`.
- The original `cs61c-lab` tag is also preserved under its exact name, `lab00-backup`.
- Each imported directory has exactly the same Git tree as its source's main branch at migration time, including hidden files and file modes.
- [ARCHIVE-MANIFEST.json](ARCHIVE-MANIFEST.json) records source commit/tree IDs, ref mappings, and backup bundle checksums.

To inspect original history, use `git log archive/<repository>/main` or the branch links above. Before an import merge, the original commit trees use their original root-level paths.

## Licenses

Original license files remain in their source directories, unchanged. There is no new blanket license for this collection; each source's existing terms continue to apply. Repositories without an explicit license do not acquire a new license through this archive.
